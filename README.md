# Фраза — совместная музыкальная доска

Для знакомства и запуска: [инструкция для коллеги](COLLEAGUE_GUIDE.md). Для AI-помощника: [контекст проекта](AI_HANDOFF.md).

Первая версия для преподавателя и ученика: свободная доска со стикерами, текстом, рисованием, нотным станом, аккордами и вокальными пометками. Откройте одну ссылку в двух браузерах: изменения и курсоры появляются у обоих участников. При одновременном изменении одного объекта сохраняется последнее дошедшее до сервера изменение.

## Запуск на своём компьютере

Установите Node.js версии 24 или новее. В папке проекта выполните:

```bash
npm start
```

Откройте `http://localhost:3000`, создайте доску и скопируйте ссылку кнопкой «Поделиться». База создаётся в `data/boards.sqlite`. Для остановки нажмите Ctrl+C. Для проверки сервера используйте `npm test`.

## Размещение на Linux-сервере с Docker

1. Загрузите эти файлы в свой GitHub-репозиторий и склонируйте его на сервер.
2. В папке проекта запустите `docker compose up -d --build`.
3. Настройте ваш веб-сервер как HTTPS reverse proxy: домен направляет запросы на `http://127.0.0.1:3000`. Для потока событий отключите буферизацию и установите достаточно длинный таймаут. Пример для Nginx внутри блока `server` с настроенным TLS:

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_buffering off;
    proxy_read_timeout 3600s;
}
```

4. Откройте домен по HTTPS, создайте доску и проверьте работу в двух браузерах. Копирование ссылки в буфер обмена требует HTTPS или localhost.

Данные находятся в Docker volume `fraza-data`. При обновлении запускайте `docker compose up -d --build`; не удаляйте volume. Настройте регулярные резервные копии базы: безопаснее сначала остановить контейнер командой `docker compose stop`, сделать копию volume, затем запустить `docker compose start`. Не удаляйте volume при обновлении. Для восстановления храните проверенную копию отдельно от сервера.

Без Docker: установите Node.js 24+, скопируйте проект и запустите `npm start` под менеджером процессов. Переменные окружения `PORT`, `HOST` и `DB_PATH` настраивают порт, адрес и путь SQLite. Запускайте только один экземпляр сервера: текущая рассылка событий находится в памяти процесса и не синхронизируется между экземплярами.

## Доступ и ограничения

- Ссылка содержит случайный секрет. Каждый, у кого она есть, может читать и изменять доску; не публикуйте её. Аккаунтов и разграничения прав пока нет. При утечке ссылки отозвать её в интерфейсе пока нельзя.
- Участники видят курсоры при движении мыши. Если соединение пропало, показывается предупреждение; несохранённое действие нужно повторить. Поток переподключается автоматически.
- Тексты песен и заметки хранятся в базе сервера. Настройте HTTPS, доступ к серверу и резервное копирование до приглашения пользователей.
- Нотный стан схематичный: есть ограниченный набор длительностей и прослушивание, но нет полноценной нотной записи. Экспорт, отмена действий и загрузка файлов не реализованы. Каталог досок хранится в текущем браузере, а не в учётной записи.
- Supabase не используется: эта версия работает с локальным SQLite, чтобы её можно было поднять без облачных ключей. GitHub используется для хранения и доставки исходного кода; размещение происходит на вашем сервере.
