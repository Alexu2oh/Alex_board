# Первая версия музыкальной доски

Преподаватель создаёт доску, копирует ссылку и открывает её вместе с учеником. Оба видят курсоры и изменения в реальном времени; содержимое переживает перезапуск сервера. Доска остаётся свободным полем: стикеры, текст и карандаш дополняются нотным станом, аккордами и вокальными пометками.

Первая версия доступна по случайной секретной ссылке: каждый обладатель ссылки может редактировать доску. Учётные записи, права просмотра, каталог личных досок и импорт аудио в эту версию не входят. Ссылка — секрет; она не предназначена для публикации. Владелец сервера отвечает за HTTPS и резервное копирование.

Выбранная реализация: Node.js, SQLite на локальном диске сервера, HTTP и поток событий для синхронизации. Каждая операция изменяет отдельный объект, чтобы независимые одновременные правки не перезаписывали всю доску. При одновременном редактировании одного объекта побеждает последнее изменение; при потере соединения интерфейс предупреждает пользователя. Состояние курсоров временное, не сохраняется. Клиент после переподключения загружает актуальное состояние. Размещение через Docker или Node.js; Supabase в этой версии не требуется.

Нотный стан — визуальная запись высоты, без воспроизведения и полноценной музыкальной нотации. Зум, перемещение поля, перемещение и удаление объектов доступны локально. Сервер проверяет размер и форму запросов и ограничивает доступ к доске её случайным идентификатором.
